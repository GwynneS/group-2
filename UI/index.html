Install the extension

  1. Unzip buddy-extension.zip. You'll get a buddy-extension folder.
  2. Chrome, Edge, Brave: open chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder.
  3. Firefox: open about:debugging → This Firefox → Load Temporary Add-on and pick manifest.json inside the folder. Then allow it to access all websites in the add-on's permissions.
  4. Reload the pages you have open in that browser. The status above changes to Extension: connected.
